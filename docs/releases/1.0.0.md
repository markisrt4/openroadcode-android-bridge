# ORC Companion 1.0.0

First official release of the OpenRoadCode Android companion app.

- Simple mode with subsystem switches and an Advanced mode for detailed controls.
- Navigation, Automotive, Radio/ADS-B, Media audio, Video and Environment screens.
- Runtime start/stop controls, connected-device names and paired computing units.
- Live performance diagnostics, live logs, optional messaging and simulation controls.
- Refined connection setup, accessible button layouts and distinct inactive labels.

## Install or update

Download `orc-companion-v1.0.0.apk` and open it with Android's package installer,
or use `development/termux/install_latest_apk.sh` from an up-to-date main checkout.
Version code 40, package `org.openroadcode.androidbridge`, Android 8.0+.
The normal main installer verifies CI for the current checkout commit.

## Distribution and known issue

This release deliberately distributes the existing debug/development build,
signed with the same shared development certificate as earlier RC versions, so
it can update existing installations. It is debuggable and is not a private-key
production build. The private signing pipeline is prepared but not provisioned;
changing signing identity requires a separate migration plan.

Google Play Protect currently shows “Harmful app blocked” during sideloaded
installation. Removing SMS/contacts permissions in an isolated experiment did
not clear the warning. The cause is unconfirmed; no clean antivirus verdict or
Google approval is claimed. APK signature/ZIP checks do not establish safety.
Optional SMS, contacts, location, Bluetooth, camera and audio access remains
permission-controlled. Keep Play Protect enabled.

## Verification

Debug and release unit tests, APK metadata and signature verification run in
GitHub Actions. SHA256SUMS and APK review evidence accompany the release.
